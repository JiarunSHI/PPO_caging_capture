# IEEE conference-format basis

The English manuscript is formatted against the generic IEEE conference conventions. A target conference may impose a different page limit, paper size, anonymity rule, or keyword policy; its own template takes precedence.

Official IEEE references:

- IEEE Conference Author Center, Authoring Tools and Templates: https://conferences.ieeeauthorcenter.ieee.org/write-your-paper/authoring-tools-and-templates/
- IEEE Conference Author Center, Structure Your Paper: https://conferences.ieeeauthorcenter.ieee.org/write-your-paper/structure-your-paper/
- IEEE conference publishing information: https://events.ieee.org/planning-basics/ieee-conference-publications/publishing-information-for-ieee-conference-authors/
- IEEE-hosted conference template example: https://ewh.ieee.org/r10/calcutta/calcon2020/doc/CALCON%202020_Manuscript_Template.pdf

Applied conventions:

- English manuscript with an abstract shorter than 250 words and five index terms.
- US Letter paper, no manuscript page numbers, single spacing, and two 3.5-in columns separated by 0.25 in.
- Times/Times New Roman: 24-pt title, 10-pt body and equations, 9-pt abstract/index terms, and 8-pt captions/references/table text.
- Roman-numbered centered primary headings, lettered italic secondary headings, and numbered run-in tertiary headings.
- Figure captions below figures; table titles above tables; Arabic equation numbers aligned at the right by IEEEtran.
- Mathematical vectors and matrices are bold, scalar variables are italic, operators/functions are upright, and physical units use upright Roman symbols.
- Large algorithm and inference figures use double-column `figure*` placement so labels remain readable in print.

The LaTeX source uses `\documentclass[conference]{IEEEtran}` and should be treated as the normative typesetting source. The DOCX and HTML versions are editable/preview derivatives.
